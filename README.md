# 🛡️ Blue Team Portfolio | DFIR • SOC • Threat Hunting

Este repositorio reúne laboratorios, write-ups y ejercicios prácticos relacionados con **Digital Forensics**, **Incident Response**, **SOC Operations**, **Threat Hunting** y análisis de sistemas Windows. El objetivo es documentar el proceso de investigación de cada desafío, mostrando el razonamiento utilizado y las herramientas empleadas para llegar a cada conclusión.

Actualmente me encuentro formándome en ciberseguridad con un enfoque en **Blue Team**, realizando laboratorios prácticos y desafíos que me permiten desarrollar habilidades en análisis forense, respuesta a incidentes y detección de amenazas.

---

# 🎯 Objetivos

- Documentar investigaciones DFIR.
- Mejorar habilidades de análisis forense en Windows.
- Practicar técnicas de Threat Hunting.
- Familiarizarme con herramientas utilizadas por analistas SOC.
- Aprender Linux.
- Construir un portfolio técnico.
